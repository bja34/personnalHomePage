# 👋 Welcome to My Portfolio Website

Hello there! I'm Mikael Baldassin, and this is the repository for my personal portfolio website. This project represents a fresh take on my online presence.

## 🌟 About This Project

This website serves as a showcase of my work and skills as a Full Stack Developer. It's designed to be:

- 🎨 Clean and modern
- 🌐 Fully responsive
- 🌍 Bilingual (French/English)
- ⚡ Smooth and interactive

## 🛠️ Built With

- HTML5
- CSS3 (with modern features like CSS Variables and Flexbox)
- JavaScript (Vanilla)
- Love and attention to detail

## ✨ Features

- **Smooth Animations**: Carefully crafted entrance animations for a polished user experience
- **Responsive Design**: Looks great on everything from mobile phones to large desktop screens
- **Bilingual Support**: Switch seamlessly between French and English
- **Dark/Light Theme**: Easy on the eyes, day or night
- **Portfolio Showcase**: Clean presentation of my projects and skills
- **Contact Form**: Direct way to get in touch with me
